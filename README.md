<h1 align="center">HACK4U</h1>

أداة اختبار اختراق بسيطة ومفتوحة المصدر تهدف لمساعدة المتعلمين الجدد في مجال الأمن السيبراني.

---

## ⚙️ الوظائف الحالية:

- كشف النظام المستهدف
- واجهة أساسية للأداة
- هيكلة منظمة للمشروع
- دعم Termux
